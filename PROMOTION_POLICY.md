# Promotion rule (declared before reserved model scoring)

The development-selected pipeline remains a challenger. Recommend replacing the
original Poisson reference only if its mean game points improve in both reserved
seasons and the combined approximate week-block bootstrap 95% interval for the
point difference lies entirely above zero. Otherwise retain the reference and
report the result as inconclusive or worse. This rule does not tune model settings
or trigger another reserved-season search. A prospective test is still necessary.
